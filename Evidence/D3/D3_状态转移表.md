# D3 事件状态转移说明
状态集合：OPEN(待处理)、HANDLING(处理中)、RECOVERED(已恢复)

| 当前状态 | 允许跳转至 | 触发条件 |
|---|---|---|
| 无 | OPEN | 检测到zone产生环境异常，新建事件 |
| OPEN | HANDLING | 用户点击【执行干预】干预按钮 |
| HANDLING | RECOVERED | 收到后续MQTT新数据，环境满足恢复条件（仅新数据驱动，按钮不能直接恢复） |
| HANDLING | OPEN | 收到新MQTT数据，环境指标进一步恶化 |
| OPEN / HANDLING | 保持不变 | 仅点击按钮，没有收到新MQTT数据 |

## 消息健壮性规则
1. 消息去重：使用 zoneId + time 作为去重标识，重复消息不重复执行业务
2. 乱序消息：收到消息内部按time时间戳排序，再做状态判断
3. 迟到消息：时间早于事件当前时间；**事件已经RECOVERED时，迟到消息只追加历史，禁止修改事件状态**

## 禁止非法跳转
1. 禁止 OPEN 直接跳转到 RECOVERED，必须经过HANDLING干预动作
2. 禁止通过UI按钮直接把事件设置为RECOVERED，恢复必须由MQTT数据触发
